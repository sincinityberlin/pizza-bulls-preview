Wie kann ich meine Cookie-Einstellungen ändern?

Sie können Ihre Cookie-Einstellungen jederzeit über die Cookie-Einstellungen ändern. Sie können dann die Schieberegler auf „Ein“ oder „Aus“ stellen und dann auf „Fertig“ klicken. Möglicherweise müssen Sie Ihre Seite aktualisieren, damit die Einstellungen wirksam werden.

Sie können Cookies jederzeit löschen oder konfigurieren, indem Sie Ihren Internet-Browser konfigurieren. Bitte besuchen Sie die speziellen Hilfeabschnitte Ihres Browsers, um Informationen über die Cookie-Einstellungen zu erhalten:

  • Internet Explorer
  • Chrome
  • Firefox
  • Safari Web und Safari für iOS

Um Informationen zu anderen Browsern zu finden, besuchen Sie die Website des Browser-Entwicklers.
